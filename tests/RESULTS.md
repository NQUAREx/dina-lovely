# Фактические проверки

- Godot 4.7.2: импорт и однопоточный Web Release Export выполнены.
- 51 проверка `tests/playthrough.gd` прошла: достижимость всех писем, блокировки выходов, три волны, урон, повтор комнаты, сад, шифр, открытка, сохранение и восстановление.
- Native Compatibility preview: визуально проверены меню, комнаты и открытка. По результатам исправлены положение камеры у границ и высота меню.
- HTTP в подпапке: ресурсы загружаются, WebAssembly стартует; IndexedDB создаётся. Специальные COOP/COEP заголовки не используются.
- Ограничение: Chromium в этом proot использует SwiftShader, теряет WebGL context и показывает пустой canvas. Полное браузерное прохождение и производительность не подтверждены. Нельзя считать 60 FPS проверенными.
- Реальный Safari/iPhone и аппаратный Android Chrome недоступны для проверки. Перед вручением подарка необходима проверка на устройстве получателя.

Скриншоты `native_*.png` получены из запущенного исходного проекта, а не из браузера. Они не доказывают корректность WebGL на целевых устройствах.
