# Проверки 8 ноября 2026

- Godot 4.7.2: импорт, Compatibility renderer, однопоточный Web Release Export выполнены.
- 51 проверка игрового состояния прошла в native headless и в отдельной WebAssembly QA-сборке внутри Firefox. Проверены достижимость всех писем, блокировки выходов, три волны, урон, повтор комнаты, выращивание сада, финальный шифр, открытка, сохранение и восстановление. Результат Web: `finished=true`, `letters=7`, `passed=51`.
- Release-сборка в Firefox с Mesa/softpipe отрисовала меню, вступление, лабиринт и интерфейс. Проверены кнопки и клавиатурный ввод, запись `garden_save_v1.json` в IndexedDB и меню продолжения после reload.
- Проверены портретная раскладка и отображение предложения повернуть экран. Подсказка увеличена для телефонов.
- Для touch введена явная обработка UI-кнопок и отслеживание пальца джойстика. Синтетическими W3C touch events проверены запуск через кнопку, движение джойстиком, отпускание и последующее открытие меню. Это эмуляция, а не настоящий телефон.
- Потеря WebGL context или ошибка загрузки теперь показывают понятную кнопку перезапуска вместо пустого canvas. Сохранённые письма остаются в IndexedDB.
- HTTP работает в подпапке; специальные COOP/COEP заголовки не используются.

## Границы проверки

51 автоматическая проверка вызывает методы игрового состояния, а не проходит весь маршрут клавиатурой. Она проверяет механику всех глав внутри настоящего браузерного runtime. В production отсутствуют тестовые команды и переключатели уровней.

Chromium/SwiftShader в данном Termux/proot теряет графический контекст; Firefox/Mesa в той же среде отрисовывает игру. Это ограничение воспроизводимого локального Chromium QA, а не доказательство работы на всех Chrome-устройствах.

Реальные Safari/iPhone и аппаратный Android Chrome недоступны. Цель 60 FPS на телефонах не подтверждена измерениями: software renderer для этого нерепрезентативен. Не заявляем проверку реальных устройств.

`web_*.png` и `touch_*.png` — браузерные screenshots. `native_*.png` — исходный native preview. Личная фотография ещё не предоставлена: в открытке используется авторская иллюстрация, заменяемая через JSON.
