# Сад — браузерная игра

Небольшое пиксельное приключение для телефона: семь комнат, лабиринт, поиск записок и камешков, движущиеся препятствия, раскопки, бой и сад. Проект написан на Godot 4.7.2 и GDScript.

[Играть в браузере](https://nquarex.github.io/dina-lovely/)

## Запуск

- **iPhone:** откройте страницу в Safari, выберите «Поделиться» → «На экран Домой» и запускайте через созданную иконку.
- **Android:** откройте страницу и нажмите кнопку входа. Браузер запросит полноэкранный режим, если поддерживает его.
- Игра рассчитана на вертикальную ориентацию и сенсорное управление. Для компьютера игровой режим не предусмотрен.
- На первом экране включите звук. Он также переключается в настройках.

Слева расположен виртуальный джойстик, справа — контекстное действие и атака. Наведение в бою автоматическое. Меню открывается кнопкой паузы в верхней панели.

## Игровые системы

- Случайный лабиринт, скрытые предметы, подвижная изгородь и интерактивные растения.
- Тёмная комната с фонариком, препятствия, раскопки и выращивание разных цветов.
- Семь волн боя, несколько видов оружия, стрелки, босс и одна аптечка.
- Сбор камешков и составление последовательности по подсказкам в записках.
- Просмотр найденных записок, статистика, аксессуары и спутник.
- Проходы между комнатами с сохранением состояния; неактивные комнаты не симулируются.

## Редактирование текстов

Изменяйте `content/letters.json`, сохраняя структуру и существующие ID:

- `letters`: записки с полями `id`, `title`, `text` и необязательным `image`.
- `ui`: подписи интерфейса; назначение каждой настройки описано в `_comment`.
- `puzzle`: символы и распределение подсказок по комнатам.
- Остальные поля задают название приложения и содержимое финального экрана.

После коммита обновите страницу: JSON загружается заново без повторного экспорта игры. Для загрузки текстов требуется интернет. Новые изображения и другие игровые ресурсы необходимо включить в повторный Web Export. Пути вида `res://assets/example.png` относятся к ресурсам Godot.

## Открытие и экспорт

Установите Godot 4.7.2 и официальные Export Templates той же версии. Откройте `project.godot` в редакторе. При наличии настроенного локального toolchain доступны команды:

```bash
./tools/godot.sh --headless --editor --import
./tools/godot.sh --headless --export-release Web docs/index.html
python3 tools/finalize_web.py
python3 -m http.server 8766 --directory docs
```

Откройте `http://127.0.0.1:8766/` на телефоне через доступный адрес компьютера либо используйте мобильную эмуляцию для проверки оболочки. Запуск через `file://` не поддерживается.

После каждого экспорта обязательно выполняйте `finalize_web.py`: он добавляет мобильную оболочку, загрузчик, manifest, версии ресурсов и транспортное сжатие WASM. Для этого скрипта нужен Pillow.

Экспорт использует **Compatibility Renderer**, один поток, HTML и WebAssembly. Специальные COOP/COEP-заголовки и серверная часть для игрового процесса не нужны. Поддержка полноэкранного режима, звука и установленного веб-приложения зависит от браузера.

## GitHub Pages

В настройках репозитория выберите **Pages → Deploy from a branch → main → /docs**. Публикуйте все необходимые файлы из `docs/`, включая HTML, JS, PCK, WASM и сжатые транспортные файлы. `.nojekyll` предотвращает обработку сборки Jekyll. Пути ресурсов относительные и поддерживают размещение в подпапке репозитория.

## Сохранения и ресурсы

Прогресс хранится локально через Godot `user://`; в браузере используется его постоянное хранилище. Очистка данных сайта удалит сохранение. Новая игра сбрасывает игровой прогресс.

Музыки нет. Используются звуковые эффекты и окружение. Источники и условия использования перечислены в `assets/SFX-CREDITS.md` и `assets/audio_sources.json`; лицензии шрифтов находятся в `assets/`. Часть RPG-звуков взята из предоставленной записи и не относится к CC0. Пиксельные игровые текстуры созданы для проекта.

Вибрация работает при поддержке браузером; стандартная Vibration API в iOS недоступна. Реальные Safari/iPhone в текущем окружении не тестировались. Проверки выполнялись в Godot и мобильной оболочке Chromium.
