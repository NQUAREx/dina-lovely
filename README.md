# Тебе. От меня. — Mobile Portrait

Романтическая touch-only игра на Godot 4.7.2 / GDScript. Только браузер на телефоне, только вертикальная ориентация. Семь комнат, двенадцать записок, два секрета, сад и финальная открытка. Серверной части нет.

Игра: https://nquarex.github.io/dina-lovely/

## Запуск на телефоне

**iPhone:** откройте ссылку в Safari → «Поделиться» → «На экран Домой». Если показан переключатель «Открывать как веб-приложение», включите его. Запускайте через иконку. До запуска из Home Screen игра показывает инструкцию установки. Web app открывается без адресной и нижней панели Safari.

**Android:** нажмите «Войти в сад». В это касание запрашивается Fullscreen API и блокировка portrait, если браузер их разрешает. Полноэкранный режим нельзя гарантированно включить без действия пользователя: браузер сам контролирует разрешение. После выхода из fullscreen следующее касание повторяет запрос.

Альбомная ориентация закрыта предложением вернуть телефон вертикально. На компьютере показывается сообщение открыть ссылку на смартфоне. Клавиатурное управление и наведение мышью удалены.

## Управление

Левая часть — свободный виртуальный джойстик. Справа — контекстное действие и кнопка атаки в бою. Наведение автоматическое. Меню — кнопка паузы сверху. Интерфейс и открытка рассчитаны на 540×960 с масштабированием под экран.

## Звук и вибрация

Музыка полностью удалена. Используются готовые лицензированные эффекты Kenney, Tinysized SFX и Gunshot Sounds вместо синтезированных сигналов. Набор включает: шаги по траве и камню, вода, наполнение лейки, бумага, интерфейс, атаки, попадания, сундук и редкие звуки окружения. До десяти голосов могут звучать одновременно. Звук отключается в настройках.

На поддерживаемых Android-браузерах `navigator.vibrate()` даёт короткий отклик на касания, удары и события. **В WebKit/iOS стандартная Vibration API не поддерживается**, поэтому там остаются звук, частицы и визуальная тряска. Добавление на Home Screen не включает отсутствующую API.

Официальные источники:

- [Apple: standalone web applications](https://developer.apple.com/library/archive/documentation/AppleApplications/Reference/SafariWebContent/ConfiguringWebApplications/ConfiguringWebApplications.html)
- [WebKit: Home Screen web apps and manifest display](https://webkit.org/blog/13878/)
- [W3C Vibration API: WebKit position](https://www.w3.org/TR/vibration/)

## Персонализация

`content/letters.json`: `recipient`, `signature`, `card_title`, `card_text`, `photo`, `photo_caption`. Для совместной фотографии положите файл в `assets/photo.jpg`, задайте `"photo":"res://assets/photo.jpg"` и повторите экспорт. Сейчас используется авторская иллюстрация.

Письма находятся в массиве `letters`: `id`, `title`, `text`, необязательный `image`. Сохраняйте ID. Финальный порядок: **Солнце → Цветок → Звезда**.

## Сборка и публикация

```bash
./tools/godot.sh --headless --import
./tools/godot.sh --headless --export-release Web docs/index.html
python3 tools/finalize_web.py
python3 tools/serve.py
```

Локальный адрес: `http://127.0.0.1:8766/love-in-bloom/docs/`. Через `file://` игра не запускается.

`finalize_web.py` добавляет mobile launch gate, manifest, iOS Home Screen instruction и восстановление после ошибки загрузки/WebGL. Запускайте его после каждого экспорта. GitHub Pages публикует `main` → `/docs`; все пути относительные. В репозитории должны оставаться все файлы `docs/`, включая WASM, PCK, JS и manifest.

Renderer — Compatibility; Thread Support выключен, COOP/COEP и SharedArrayBuffer не требуются. В Termux/proot `tools/godot.sh` использует process-local обход ошибки native `scandir64` при недоступном `/dev`. Он не входит в браузерный runtime.

## Ресурсы и сохранения

`tools/create_assets.py` воспроизводит оригинальные пиксельные ассеты и sound-design bank. Героиня полностью закрыта: платок, длинное платье, перчатки и непрозрачная вуаль. Дыхание, походка и покачивание ткани дополнены движением при рисовании. Финальный сундук рисуется с масштабом 3×.

`user://garden_save_v1.json` хранится в браузерном IndexedDB. Письма, секреты, сад, завершённые главы и финал сохраняются. Очистка данных удаляет прогресс. Хранилище Home Screen web app может отличаться от обычной вкладки Safari: начинайте игру через иконку.

Проверки и ограничения: `tests/RESULTS.md`. 60 FPS на реальных iPhone/Android не заявляются без измерений. В текущем proot Chromium/SwiftShader имеет известную проблему графического контекста; реальный Safari здесь недоступен.

## Обновлённые механики

- Коридоры соединяют комнаты снизу вверх. Южный выход возвращает назад. Соседняя комната загружается внутри анимации, одновременно работает только текущая. Незавершённый бой при повторном входе начинается заново.
- Каждому из шести растений сначала нужна очистка граблями, затем одна порция удобрения и два полива. У каждого цветка свои размер, окраска и длительность роста. Лейка вмещает шесть порций. Удобрение берётся в пакете рядом с лейкой. Стадии и оставшееся время сохраняются; вне сада рост приостановлен. Ранее завершённые цветы сохраняют завершение.
- У южного входа в боевую комнату стоят РПГ, автомат и меч. Меч наносит широкий ближний удар, автомат стреляет при удержании, ракета взрывается по площади. Оружие можно менять на стойках.
- Текст и списки прокручиваются пальцем, включая журнал с кнопками. Перетаскивание отменяет нажатие строки. Светлячки имеют координаты карты и не следуют за камерой.
- Тексты переписаны вручную: подходящего anti-slop skill в установленных ресурсах не оказалось. Новое название — «Тебе. От меня.».

Точечная проверка: `XDG_DATA_HOME=/tmp/garden-upgrade-test ./tools/godot.sh --headless --script tests/upgrade_checks.gd`.

## Три комнаты после лабиринта

Порядок: лабиринт → темнота → движущиеся балки → газон с лопатой → бой → сад → финал. Фонарик лежит на подставке в южном коридоре тёмной комнаты; его нужно взять кнопкой действия. Он освещает небольшой сектор впереди и ближайший круг вокруг героини; остальная карта закрыта чёрным туманом. Для выхода нужны три записки. Кратковременно появляющиеся черепа не наносят урон.

В узком проходе три балки движутся по X. Нужно дождаться свободного края и пройти мимо каждой. Столкновение отодвигает на юг без потери здоровья. На газоне возьмите лопату и копайте в любом месте. Случайная позиция письма и выкопанные ямки сохраняются.

Сохранения версии 1 автоматически переносят старые комнаты боя/сада/финала с индексов 1/2/3 на 4/5/6; письма и прогресс не сбрасываются. Новые комнаты доступны через обратные переходы.

## Обновление проходов и предметов

Коридоры имеют открытое продолжение и один ряд боковых стен, а не заполненную стенами полосу. Визуальный ориентир для читаемого прохода: [скриншоты Soul Knight](https://spuf.org/2017/08/02/soul-knight/); оригинальные ассеты игры не использованы. Фонарик берётся вручную с видимой подставки.

Газон очищен от декора и заранее отмеченных ям. После подбора лопаты копать можно в любой точке внутреннего газона; действие длится 0,5 с. Место письма случайно выбирается для новой игры и сохраняется. Рядом с ним игра сообщает, что вы близко. Старый результат найденного письма сохраняется.

Каждое оружие снимается со стойки один раз. Между собранными видами можно переключаться кнопкой «Сменить оружие». Автомат получил AK-pattern sprite с горизонтальным отражением при стрельбе влево, без переворота. Ракета стартует медленно и ускоряется до игровой скорости; выхлоп, дым и взрыв рисуются отдельно. Это игровая модель, не физическая симуляция реального боеприпаса.

Лейка видна в свободной руке после подбора. При поливе перемещается к растению; начало струи вычисляется из положения её носика и угла наклона. Генератор графики больше не генерирует и не перезаписывает звуки. Источники и изменения аудио перечислены в `assets/SFX-CREDITS.md`, пофайловая карта — `assets/audio_sources.json`.

## Исправление геометрии и случайности

- Лабиринт получает новый случайный seed в новой игре; seed сохраняется, поэтому при возвращении карта не перестраивается. Расположение записок и мелкого декора зависит от него. Миникарта удалена. Южная граница первой комнаты и северная граница последней закрыты; оставшиеся переходы расположены по центру.
- Изгородь рисуется сеточными тайлами 48×48, без покачивания и наложения соседей. Окружение вне карты остаётся пустым: светлячки и лепестки рисуются только над допустимыми клетками.
- В лабиринте звучит тихая запись птиц, при контакте с кустами — шорох. В ночной комнате — запись сверчков. Свет остаётся только от фонарика и его подставки; черепа исчезают за 0,8 с. В комнате добавлены домик, деревья, пруд, скамья и диагональная каменная дорожка.
- В узкой комнате стены по одному блоку, за ними пустое пространство без деревьев. В центре — дополнительная записка. Удар балки возвращает к началу.
- Газон стал меньше. Копание занимает 0,25 с; найденная записка появляется на земле и открывается отдельным действием. Лопата и лейка отображаются в руке только в своих комнатах и возвращаются на место при выходе.
- В руках только одно оружие. При подборе другого прежнее падает под ноги. Текст виден только рядом с ещё лежащим оружием. Ракета убивает прямую цель, но не наносит урон по площади.

### Тексты без повторного экспорта
При открытии страницы игра загружает `content/letters.json` прямо из ветки `main`
репозитория `NQUAREx/dina-lovely` с `cache: no-store`. После изменения файла на
GitHub обновите страницу или полностью откройте веб-приложение заново. Для
другого репозитория измените URL в `tools/mobile_shell.js` и повторите экспорт.
В Web Export нет запасного текста: сначала загружается JSON, затем появляется стартовый экран. При ошибке сети показывается кнопка ↻ для повторной загрузки. Для игры нужен интернет.

`game_title` — название игры; `letters` — письма; поля `card_*`, `recipient`,
`signature` — открытка. В `ui` собраны подписи кнопок, подсказки, названия комнат
и остальные игровые тексты. У каждого английского ключа есть поля `_comment`
(пояснение) и `text` (редактируемый текст). Меняйте только `text`.
Сохраняйте `%d`, `%s` и другие шаблоны форматирования в соответствующих строках.


### Предметы, письма и сад
Одновременно в руках один инструмент или одно оружие. При смене предыдущий
предмет остаётся под ногами; его положение сохраняется. При выходе из комнаты
инструмент/оружие остаётся в той комнате. У АК-47 магазин на 30 патронов,
автоматическая перезарядка занимает 1,8 секунды; счётчик и прогресс видны в мире.

Грядки располагаются случайно при новой игре, их положение стабильно в текущем
сохранении. К каждой ведёт извилистая каменная дорожка. В саду можно посидеть на
лавочке или качеле; действие «Встать» или движение возвращает к ходьбе.

При чтении конверт раскрывается и лист бумаги вылетает к камере. Лист можно
прокручивать; крестик закрывает его. Пустой конверт остаётся на месте, письмо
доступно в журнале.


### Изгородь и тропинки
Край изгороди мягкий: героиня может слегка продавить листву, но твёрдая
сердцевина остаётся непроходимой. Кусты и декоративные цветы смещаются от
прикосновения и возвращаются на место. Ягоды растут в отдельных кустах
изгороди; две секретные записки скрыты внутри доступных с дорожки кустов.

Балки теперь разделены промежутками 4,4 клетки, комната удлинена. При новом
запуске игры меняются ширина, скорость, фаза и характер движения балок;
при переходах внутри одной сессии параметры сохраняются.

Дорожки в саду и ночной комнате образуют общую разветвлённую сеть плавных
кривых с грунтовым основанием и нерегулярными камнями. Их форма зависит от
случайного зерна текущей игры. Для каждого вида цветка есть собственные
рисунки рассады, бутона и цветения.


### Формат текстов и финальная загадка (schema_version = 2)
Все отображаемые тексты находятся в `content/letters.json`. В коде нет русских
строк по умолчанию: только английские идентификаторы. Пример:

```json
"read_letter": {
  "_comment": "Кнопка действия возле найденного конверта.",
  "text": "Читать"
}
```

JSON не допускает комментариев `//`. Для пояснений используются поля
`_comment` и `_comments`; они не выводятся игроку. Английские ключи, ID записок
и имена подстановок переименовывать не нужно.

Финальная цепочка содержит семь различных символов. В новой игре случайно
выбираются их порядок, распределение семи подсказок между комнатами и записка
с подсказкой в каждой комнате. Одна подсказка задаёт начало цепочки, остальные
шесть задают непосредственных соседей. Подсказки показываются и при первом
чтении, и при повторном просмотре в журнале. Порядок и выбранные записки
хранятся в сохранении, поэтому обновление страницы не меняет загадку.

В финальной комнате лежит записка `final_hint`. Для открытия нужны все семь
записок с подсказками. Кнопки принимают любую последовательность из семи
нажатий, включая повторы; промежуточная правильность не раскрывается.
Сундук проверяет весь ответ. Отдельная кнопка сброса позволяет начать ввод
заново; введённые символы видны под HUD.

Шаблоны `riddle_start_clue` и `riddle_link_clue` в `ui` можно редактировать,
сохраняя `{symbol}`, `{before}`, `{after}`. Не вписывайте фиксированный ответ
в тексты писем. Раздел `puzzle.room_letters` задаёт кандидатов записок каждой
комнаты; `puzzle.symbols` содержит ID нарисованных символов.

Web Export получает имя ресурса `game.<hash>.pck` и версию `mobile.js`, чтобы
браузер не смешивал новую структуру JSON со старым кодом игры. `docs/index.pck`
также сохраняется как стандартный результат экспорта.


### Мягкая листва, аудио и стадии грядок
Твёрдые сердцевины соседних кустов соединены без щелей. Шесть частей листвы
каждой клетки имеют независимые пружины; движение листвы не разрывает стены.
Для декоративных цветов есть отдельные кадры нормального, согнутого и
примятого к земле состояния с восстановлением после ухода героини.

Короткие звуки заранее загружены через `scripts/audio_bank.gd`. Убрана
начальная тишина у поедания ягод, взмахов и перезарядки; боевые эффекты
импортируются без сжатия. В Web используется Sample playback. Пули сохраняют
проверку всего отрезка полёта за кадр. Задержка физического вывода звука зависит
от устройства и браузера.

Грядка: заросшая трава → пустая земля после граблей → порошок после удобрения
→ влажная земля после полива → зелёный росток без бутона → после второго
полива закрытые бутоны. У каждого вида собственные рисунки. Камешки отмечают
край грядки; дорожки проходят рядом и плавно растворяются у концов.


### Следы и непрерывные дорожки
Листва лабиринта не имеет прямоугольной подложки. Мягкий край увеличен до
16 пикселей с открытых сторон, а соединения сердцевин остаются сплошными.
Следы левой и правой ноги появляются по пройденному расстоянию, включая
коридоры, и исчезают за девять секунд. Ходьба добавляет небольшие частицы;
цвет и звук учитывают фактическую поверхность тропинки.

Каждая ветка дорожки непрерывна: если случайная кривая пересекает грядку или
предмет, маршрут заранее строится вокруг препятствия. На соединениях веток
прозрачность не уменьшается; затухание есть только у свободного конца.


### План дорожек, объём изгороди и фразы загрузки
Дорожки имеют главный проход и собственные подходы к грядкам, колодцу,
лавочке, качеле и инструментам. Последний участок подходит к передней
стороне объекта, не продолжаясь за ним. Непрозрачное окончание завершается
отдельной пиксельной текстурой `path_end`, без уменьшения прозрачности.

Изгородь соединяется переходной листвой; открытая передняя грань и мягкая
тень возвращают ей высоту и объём. Шорох изгороди срабатывает при сильном
нажатии внутрь твёрдой части, а не при обычном проходе рядом.

В `letters.json` список `loading_phrases` содержит английские ключи UI-фраз.
Редактируйте соответствующие `ui.loading_*.text`. Фразы меняются каждые
1,3 секунды во время реальной загрузки Web-ресурсов; искусственной задержки
нет. Мелкие камни, цветочки, травинки и пятна на газоне генерируются по seed
и остаются привязанными к карте.


### Ворота, RPG и восстановленные естественные тропинки
Дальнейший проход закрыт физическими воротами. После выполнения задачи комнаты подойдите и нажмите «Открыть ворота»: замок откроется и упадёт, правая створка приоткроется внутрь. Левая останется прямо.
На входе ворот нет: вход и возвращение доступны всегда. Створки остаются видимыми и используют отдельную текстуру открытого положения.
Из финала можно вернуться за пропущенными подсказками: его обратный проход
остаётся доступным, чтобы старые сохранения не попали в тупик.

Тропинки — единая запечённая поверхность с плавными изгибами. Под клумбами,
колодцем, лавочкой, качелей, инструментами и письмами лежат площадки в форме эллипсов с глубиной 0,58
из того же грунта. Все концы веток входят внутрь площадок или общей сети:
отдельных обрезанных полос и полупрозрачных наложений нет. Земля клумб и
каменный бортик рисуются поверх площадок. Детали газона также запечены.

RPG перезаряжается 1,62 секунды (+20%). Пуск — короткий записанный транзиент,
взрыв — отдельный эффект с ослаблением по расстоянию до игрока. Полёт немного
замедлен; во время перезарядки в руках видна пустая труба и вставка ракеты.
Объёмная основа изгороди рисуется под актёрами. Со всех сторон листва перекрывает только часть героини ниже пояса. У найденного конверта маска ямы ограничивает только нижнюю половину.


### Дополнения окружения и боя
Мобильный экран загрузки сохраняет звёздочку и показывает прогресс по реально загруженным байтам. Во время запуска движка шкала ждёт появления меню на последнем значении.

Проекционные тени героини, врагов, деревьев и крупных предметов меняют направление относительно ближайшего работающего источника света. Ночные фонари имеют отдельный разбитый тёмный sprite и не дают света. На бетонном полу нет травы и деревьев; вместо них стоят немного ящиков и колонн.

Выстрел сдвигает оружие в руках; RPG отбрасывает героиню до 72 пикселей с проверкой стен. Полёт ракеты сопровождается отдельным циклическим записанным звуком, который останавливается при попадании и зависит от расстояния. Кровь и тела с глазами-крестиками остаются на земле при возвращении в комнату в рамках текущего запуска; новая игра их очищает.

На деревьях случайно появляются яблоки. Их можно съесть тем же действием, что и ягоды; исчезают только плоды. В изгородь лабиринта и садовую ограду добавлены деревья. Дорожки соединяют площадки у объектов в общей проекции 2.5D; открытых торцов нет.


### Коллизии, интегрированные деревья и направление RPG
Закрытая левая створка остаётся препятствием, приоткрытая правая створка не имеет коллизии. Пройти можно через просвет; кнопок перехода у открытого выхода и обратного коридора нет. Смена комнат срабатывает при физическом проходе коридора. Пруд блокирует весь видимый водоём, включая подход сверху.

Деревья в изгороди используют отдельные кроны и стволы; подвижная листва закрывает основание ствола. На бетонных уровнях увеличено количество ящиков и колонн. Перед пуском RPG героиня поворачивается к цели и выдерживает 0,16 секунды; звук, ракета и отдача появляются после этой паузы. После двух поливов используются большие раскрытые `bloom0`–`bloom5`, а не закрытые бутоны.

Площадки и ширина дорожек используют одинаковую проекцию по земле: масштаб Y = 0,58 от X. Верхний край грунта светлее, нижний темнее; клумбы, камни и растения сохраняют собственные верхние слои.

Сеть тропинок смешанная: две основные прогулочные ветки соединяются между собой, отдельные объекты получают ответвления, часть клумб делит общую развилку. Близкие инструменты могут соединяться последовательно. Крупные случайные дуги дополнены мелкой неровностью; seed сохранения делает рисунок стабильным при возвращении в комнату.

При выборе ответвления генератор учитывает близость и направление соседних тропинок: длинные параллельные участки получают штраф, а совпадающие участки могут стать общей тропой. Второй основной маршрут проходит дальше от центрального.

В лабиринте размещается до 22 деревьев с видимыми стволами; кусты с деревом не содержат ягод. Швы изгороди закрыты общей листвой; кроны сохраняют постоянную сортировку по высоте. Крайние ряды используют те же пружины листвы, что внутренние. Тень героини отсекается по плиткам земли и не проходит сквозь изгородь.


### Предметы, следы и аксессуары
Если анимация ворот пересекается с героиней, она мягко сдвигается в ближайшую свободную точку. Инструменты и фонарик поворачиваются по направлению движения; во время работы — к цели. Удобрение использует отдельный открытый пакет, частицы выходят из его горлышка. После действия восстанавливается прежний поворот героини. Над клумбами нет подписей и маркеров.

Следы используют отдельный pixel sprite; следы и пыль находятся под персонажем. В саду следы крупнее и контрастнее прежних. После еды сразу разлетаются 18 красных сердечек; затем появляются ещё десять — по одному каждые 0,2 секунды, за две секунды игрового времени.

На каждом из семи уровней размещены два необязательных аксессуара: 14 разных вещей всего. Подбор сразу надевает вещь; меню выбора нет. Есть пять слотов: головной убор, платок, платье, паранжа и часы. При замене занятого слота прежняя вещь падает рядом с героиней; её можно подобрать снова. Сброшенные вещи сохраняют комнату и положение, не дублируются при возврате. Два предмета — лимит исходных находок комнаты; сброшенная одежда хранится дополнительно. В старых сохранениях ранее вытесненные аксессуары восстанавливаются в комнатах их исходного размещения. Удалённые типы очищаются без сброса игрового прогресса. Для каждого аксессуара нарисованы 16 отдельных слоёв: четыре направления × четыре кадра движения. Все слои используют положение и кадр основного персонажа, без отдельного смещения анимации. Названия редактируются в `content/letters.json`, ключи `ui.accessory_*`.

Финальная комната украшена стойками с сердцами, венками и лентами на колоннах. Сердечки на свечах и слабый узор сердечек на полу входят в отдельные текстуры.

### Непрерывная изгородь

`scripts/hedge_field.gd` строит связный граф стен и размещает независимые кроны вдоль и поперёк его ветвей. Физические ядра разделены, текстуры листвы перекрывают стыки, общий нижний объём закрывает просветы и сохраняет тень. Крайние кусты используют ту же упругую реакцию, что внутренние. Каждая крона рисуется целиком один раз, перед героиней либо за ней. При контакте целая крона пригибается к ногам и рисуется перед героиней; после контакта плавно возвращается. Неконтактные кроны сохраняют сортировку по высоте; передние шарики целиком остаются ниже пояса. Обрезания текстур по линии пояса нет.

Исходные пиксельные материалы сохранены в `tools/art_source/`. `retained.json` фиксирует прежние несвязанные sprites; для намеренной перерисовки такого sprite сначала удалите его запись из этого списка. Проверка генератора: `./tools/godot.sh --headless --path . --script tests/continuous_hedge.gd`.

Стабильность листвы: кроны рисуются в постоянном порядке, камера округляется один раз для всего слоя. Видимая крона и ствол дерева сортируются вместе с героиней по положению корня: сверху героиня позади, снизу — впереди. Заглублённая часть корня не рисуется. Проверка пикселей при движении камеры: `./tools/godot.sh --path . --script tests/hedge_camera_stability.gd` (нужен графический дисплей).

Взаимодействие проверяет отрезок до предмета: сквозь изгородь и каменные стены предметы недоступны. Для ягод, яблок и скрытых писем разрешено дотянуться до ближней части куста. Проверка: `./tools/godot.sh --headless --path . --script tests/hedge_interaction.gd`.

Для деревьев изгороди используются текстуры обычных деревьев карты. Варианты `assets/hedge_tree*.png` заранее масштабированы в 64×96, чтобы убрать дрожание при дробном nearest-масштабировании.

Оптимизация лабиринта: видимость крон выбирается через пространственные корзины с кешированием; соседи физических ядер вычисляются при построении уровня; пружины обновляются только у контактных и возвращающихся в покой крон. Неподвижная основа стены рисуется текстурой, локальная деформация — небольшим полигональным участком. Проверки взаимодействий выполняются только для близких кандидатов. Эффекты и плотность листвы не сокращены. Проверка целых крон и локальной физики: `./tools/godot.sh --headless --path . --script tests/hedge_crown_layers.gd`.

Шорох листвы — одна зацикленная запись CC0 с плавным набором и спадом громкости. Контакт определяется теми же пружинами, что движение крон. Воспроизведение не перезапускается во время непрерывного движения; шаги используют отдельный голос. Проверка loop/envelope: `./tools/godot.sh --headless --audio-driver Dummy --path . --script tests/foliage_audio.gd`.

Белые платок и платье, два дополнительных венка, серебряная корона, сиреневое платье, белая паранжа и розовые часы имеют отдельные пиксельные pickup-иконки и все кадры наложения. Обе паранжи однотонные, с двумя прямоугольными вырезами; видна только исходная кожа, без глаз. Проверка арта: `python3 tests/outfit_art.py`.

При приближении отображаются названия доступных предметов и взаимодействий, с учётом стен. Каждая подпись привязана к верхней границе видимой текстуры своего предмета, имеет небольшой полупрозрачный серый фон без рамки и не сдвигается ради соседних подписей; при пересечении фонов остаётся подпись ближайшего предмета. Названия вещей берутся из `ui.item_*`, одежды — `ui.accessory_*`, оружия — `ui.weapon_*` в `content/letters.json`; у конвертов используется заголовок соответствующего письма. Над грядками остаются выключены подписи и индикаторы.
